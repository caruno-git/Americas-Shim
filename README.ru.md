# Americas-Shim

[English version](README.md)

Два отдельных снимка исходного кода Rust для графической совместимости и диагностики под Windows. Каждый проект собирается из своего каталога. Прежние патчи и утилиты сохранены для справки; применять патчи к опубликованным деревьям не нужно.

| Исходники | Базовый проект | Коммит | Локальные изменения |
| --- | --- | --- | --- |
| [Pareto](pareto/) | [codec-d/cool_fox](https://github.com/codec-d/cool_fox) | `f4b48ad766ddbec1a1867022cd42f7645b0dd55e` | Выбор адаптера NVIDIA, журналирование и диагностика создания конвейеров BVH |
| [ztrx](ztrx/) | [greyfinch/ztrx](https://gf.openbay.app/greyfinch/ztrx) | `90b529f878a470fec9bf07b7be316bc769a12232` | Замеры переотображения памяти и диагностика создания конвейеров BVH |

Оба снимка содержат манифесты, файлы блокировки зависимостей, исходники Rust, тесты и лицензии. Файлы для запуска, сгенерированные данные, локальные заметки и экспериментальные образцы захватов не опубликованы. Бинарная таблица BCPack не распространяется; для декодирования укажите путь к разрешённой для использования локальной таблице через `VICTORY_BCPACK_TABLES`. Право владения без проверки не подтверждается; диагностическая запись в память исключена из Pareto. Для запуска Pareto нужен явно указанный путь к исполняемому файлу (`VICTORY_GAME_EXE`).

У Pareto есть исходная ошибка сборки: в `victory-formats::texture::Layout` нет метода `bytes_from`, который вызывает GPU-крейт. Запуск и совместимость не проверялись.

Параметры утилит перечислены в [английской версии](README.md#helpers). Передавайте входные файлы сами, а журналы, захваты и кэш храните вне репозитория. Экспериментальный патч BVH, зависящий от локальных образцов, не включён. Коллекция не заявляет о проверенной совместимости или производительности.
