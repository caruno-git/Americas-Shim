# Americas-Shim

[English version](README.md)

Коллекция патчей для графической совместимости и диагностики под Windows в проектах семейства VIctory. Здесь только исходный код, без самостоятельной среды исполнения. Патчи независимы: каждый применяется к своей базовой ревизии.

| Патч | Базовый проект | Коммит | Назначение |
| --- | --- | --- | --- |
| `patches/pareto-nvidia-adapter.patch` | [codec-d/cool_fox](https://github.com/codec-d/cool_fox) | `f4b48ad766ddbec1a1867022cd42f7645b0dd55e` | Выбор адаптера NVIDIA по `VICTORY_D3D12_NVIDIA=1` и запись сведений об адаптере в журнал |
| `patches/ztrx-diagnostics.patch` | [greyfinch/ztrx](https://gf.openbay.app/greyfinch/ztrx) | `90b529f878a470fec9bf07b7be316bc769a12232` | Замеры переотображения памяти и проверка создания конвейеров BVH без их запуска (`VICTORY_BVH_CHECK=1` в диагностических сборках) |

В чистой копии нужной ревизии выполните `git apply --check <путь-к-патчу>`, затем `git apply <путь-к-патчу>`. Собирайте по инструкции базового проекта.

Параметры утилит перечислены в [английской версии](README.md#helpers). Передавайте входные файлы сами, а журналы, захваты и кэш храните вне репозитория. Экспериментальный патч BVH, зависящий от локальных образцов, не включён. Коллекция не заявляет о проверенной совместимости или производительности.
